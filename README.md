# V-RAE Homepage

Project homepage for **V-RAE: Rethinking Video Latent Spaces for Generation**.

The site presents the method, reconstruction and generation results, synchronized video comparisons, semantic probing, tFVD analysis, future-video prediction, and citation information.

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```
